📳 Вибрация (по ритму видео)

Режим:
Импульсы на реальных пиках: тик 0.2с · лого 0.43с · средний · тяжёлый удар 1.2с (вылетает MUSLIMOON) · мягкий 1.4с · success при открытии меню.

🎬 Звук интро (кино-логотип)

Звук:
Клик по варианту = сразу слышно. Лёгкие и тихие звуки (без баса-бабаха) — короткий чистый акцент на появлении логотипа. 📷 Камера = щелчок затвора. Играет вместе с видео и голосом.

🎙️ Голос-приветствие — отдельный переключатель

Голос:
🎩 «Джарвис-стиль» = наш нейро-голос + кино-обработка (глубина, «комната», фильтр) — тот же вайб без кражи чужого голоса. «голо/комм» = заметно синтетический (как ИИ-дворецкий), «мягкий» = премиум-натуральный. Кружок ▶ — прослушать.

✨ Появление меню

Стиль:
Блоки въезжают снизу по очереди (стаггер 70мс): бренд → подзаголовок → Мактаба → вкладки → разделы → поиск → режимы → случайный.
В приложении — 4 независимых переключателя в настройках: Видео-заставка · Звук интро · Голос-приветствие · Вибрация. Не понравилось что-то одно — отключил, остальное работает.
📳 Вибро на айфоне: в этом веб-макете iPhone НЕ вибрирует — iOS вообще не даёт вибрацию веб-страницам. НО в реальном приложении Telegram вибро на айфоне РАБОТАЕТ (родной Telegram HapticFeedback). На Android макет вибрирует уже сейчас. Здесь вибро показано пульсом на экране.
