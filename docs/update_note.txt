🧠 <b>Поиск по смыслу (RAG) стал легче на треть: 30,8 МБ → 19,6 МБ</b>

Чтобы задать книге один вопрос «по смыслу», приложение качало <b>30,8 МБ</b>. На телефоне это минуты ожидания — отсюда и жалобы, что «долго и как будто зависло».

Из этих 30,8 МБ почти <b>12 МБ</b> были тексты всех 7 484 мест книги, а показываются из них единицы. Теперь едет лёгкая карта (0,16 МБ), а сами тексты приезжают только для тех мест, что вы вправду увидите.

🔍 <b>Проверено, а не обещано:</b> находки не теряются. Вид записи — хадис, глава или муалляк — берётся из карты, которая есть для КАЖДОГО места; будь иначе, часть настоящих находок пропала бы молча. На пробе 5 мест: отобрано 5, показано 5, у всех настоящий текст.

Если кусок текста вдруг не догрузится, приложение так и скажет — а не покажет находку пустой.
