v723 — 🐞 Багфиксы по итогам проверки (QA)

• Клик по хадису из карточки передатчика теперь ВСЕГДА открывает именно тот хадис (для канонических книг — Муслим/Бухари/Ибн Маджа — раньше мог открыться хадис №1 вместо нужного).
• Поиск по выбранным книгам: при сбое сети больше не пустой экран — показывается понятное сообщение.
• «Совпадений нет» по Мактабе — теперь видно само пояснение, не только кнопки.
• Конструктор цепи: при удалении среднего звена формы передачи (عن/حدثنا) больше не сдвигаются на чужие стыки.
