🆕 v1718 — нейротахкик: не выносить ложный приговор из-за имени в одно слово
🤖 Разбор всех посчитанных вердиктов показал: из 29 466 «маджхуль-звено» в 5 778 «неизвестным» назначен передатчик, записанный одним словом — «سعيد», «يحيى», «قتادة», «مالك», «جابر», «حماد», «أيوب»… Это почти наверняка известные надёжные люди, которых разбор спутал с тёзкой. Для таких хадисов вердикт теперь «◻️ неполный расчёт (звено опознано неуверенно — имя из одного слова)», а не красное «цепь не держится». Настоящие маджхули (опознанные по полному имени) остаются красными. Пересчёт самих вердиктов — следующим шагом.
