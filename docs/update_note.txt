🔇→🔊 С приложения снята немота. Рой проверок нашёл главную его болезнь: 1521 место, где ошибка гасилась молча. Карточка упала при отрисовке — просто исчезала из списка. Сборник не загрузился — поиск отдавал неполную выдачу и ничего не говорил. Фильтр не создался — кнопки нет, и никто не объяснил почему. Теперь каждая такая ошибка записывается: в консоль и в журнал на странице, набрать «тихоОтчёт()». Поведение приложения НЕ менялось ни в одном месте — правкой полутора тысяч ветвей вслепую можно только сломать. Сначала беды становятся видимыми, чинить будем по доказательствам.
