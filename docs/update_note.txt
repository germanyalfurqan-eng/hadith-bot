⛓ Muslimoon v511 — «Цепочка по кодам Э1.1» полностью согласована со сверкой (верные id)

Раньше в цепи Э1.1 у некоторых передатчиков стоял ЧУЖОЙ числовой id (напр. خالد=16274), не совпадавший с авторитетной сверкой (id1768). Теперь при выровненной цепи такой id перекрывается верным — из эталона sunnah.com/Мактабы. Вместе с опознанием U-кодов (v510) цепь Э1.1 = блок «Сверка»: клик открывает ту же верную карточку.

Если у тебя «опознано 3/5» — это старый кэш: закрой и открой приложение заново.
