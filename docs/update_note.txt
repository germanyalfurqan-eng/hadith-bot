v1096 — Единый стандарт ожидания для ВСЕХ кнопок ИИ (по слову владельца): теперь на КАЖДОЙ ИИ-функции — объяснение хадиса/аята, разбор слова, свод о передатчике, огласовки, структурирование результатов, перевод — работает одно и то же: ① живая анимация вместо статичной надписи (заготовки текста, счётчик секунд, кнопка «отменить»); ② честные фазы: «ищу свободный ИИ-канал…» → «канал отвечает…» → «первый канал молчит, идём по резервным…»; ③ подпись очереди — Groq → Gemini → GitHub → NVIDIA → OpenRouter; ④ после ответа — РЕАЛЬНАЯ цепочка попыток («Groq ✕ → GitHub ✓ · 9 сек»), данные с сервера по факту вызовов; ⑤ если каналы заняты — понятный блок с причиной и кнопкой «повторить». Порядок ИИ везде одинаков: сперва бесплатные каналы по очереди, DeepSeek — в конце.
