v1202 · 📜 Все хадисы передатчика — в одном окне с фильтрами
— В карточке любого равия появилась кнопка «Все хадисы с ним» с числом мест. Открывается отдельное окно: фильтры по книге, по достоверности (صحيح · حسن · ضعيف · منكر — оценки из издания аль-Арнаута), по уникальности (есть ли этот хадис в других сборниках), по соседу в цепи передачи и поиск по номеру. На каждой кнопке фильтра стоит счётчик — сразу видно, сколько чего есть на самом деле. Раньше места равия лежали свёрнутым списком: 700 мест приходилось листать вручную.
— Честно: фильтр «марфу‘ / маукуф / мурсаль» пока не сделан — у нас нет разметки вида хадиса ни в одном источнике данных. В окне стоит отметка «🔧 будет доделано», пустого фильтра не ставили.
