📦 <b>Замерил, что приложение тянет при запуске</b>

Жалоб «долго грузится» накопилось пять, и слов в них почти нет — потому меряю, а не спорю.

При первом открытии приложение тянет <b>2,65 МБ</b> — саму страницу — и делает <b>6 запросов</b>. Всё остальное грузится только когда понадобится. Кладовая при этом на <b>2 ГБ</b>: то есть медленно бывает не «вообще», а на отдельных экранах, которые тянут крупный файл.

🔴 Один такой нашёлся: <b>Муснад Ахмада</b>. Готовый файл читалки для него на боевом отсутствует — проверил прямым запросом, отвечает «нет такого файла». Из восьми книг он единственный такой. Муснад из-за этого открывается через запасной путь и тянет <b>26 МБ</b>.

Чинить буду не выкладкой: подготовленный файл весит <b>48 МБ</b>, вдвое тяжелее нынешнего. Сначала разрежу на части, как сделано с передатчиками.
