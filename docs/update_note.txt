v524 — «Уникальные хадисы» группируются по тахриджу:

🌿 Кнопка «✨ Уникальные хадисы» теперь сворачивает версии ОДНОГО хадиса по ТАХРИДЖУ (а не только по точному совпадению текста). Счёт «уникальных» стал точнее — например по слову «бид'а» меньше повторов.
• Чем полнее тахридж по хадису — тем сильнее группировка. Где тахридж версии не связал, остаётся свёртка по тексту.
