v614 — Википедия у передатчиков (прямые статьи)
• У передатчика теперь ПРЯМАЯ ссылка на реальную статью Википедии (русская → английская → арабская), а не «поиск». Имя показывается из выверенной статьи (напр. «Катада ибн Диама»).
• Ссылки тёзка-проверены: совпадает имя + отец + эпоха + категория «передатчик/учёный/сподвижник» — чтобы не попал однофамилец (король, халиф-тёзка и т.п. отсекаются).
• Транслитерация: بن → «ибн» (а не «Бан»).
