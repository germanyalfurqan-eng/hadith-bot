🆕 v1265 — фон перестал уезжать под окном, текст больше не обрывается молча

🪟 Найдена настоящая причина «шагающих окон». Прошлая починка не работала вовсе: запрет прокрутки ставился не на тот элемент страницы. Проверили замером — при открытом окне фон спокойно уезжал на 1200 точек. Теперь фон замирает по-настоящему и после закрытия окна возвращается ровно туда, где вы читали. Для Telegram это отдельная правка: там обычного запрета прокрутки недостаточно.

📖 Текст больше не обрывается без предупреждения. Прошли по всему приложению и нашли два оставшихся места: в карточке из Мактабы длинный хадис обрезался на 2500 знаках вообще без единого знака — даже без многоточия; а в блоке сверки список критиков молча заканчивался на двадцатом имени. Теперь в обоих местах кнопка «Развернуть» с числом скрытого.

⚖️ В карточке передатчика наверх поднимаются отзывы с ВЫВЕРЕННОЙ цитатой. Раньше порядок держался только на авторитете учёного, и запись с проверенным первоисточником могла не попасть в первые шесть, а сверху стояли записи с пометкой «первоисточник цитаты не выверен». Класс признанных критиков по-прежнему идёт первым — религиозный вес выверенностью не перебивается, она сортирует внутри класса.

📗 Убрана лишняя тревога при загрузке Корана. Полоса с процентами и мегабайтами работает, второй заход мгновенный из кэша — но поверх честных цифр всё равно вылезало «дольше обычного, медленная сеть». Теперь эта приписка появляется, только если цифр нет вовсе.
